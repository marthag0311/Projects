# Customer Churn Analysis Power BI Dashboard Project

This project focused on building a structured, insight-driven dashboard about customer churn patterns.

## Specifications

- Transformed data (new column creation)
- Designed a star schema with proper relationships
- Created DAX measures
- Built a clean, interactive multi-page dashboard with slicers
