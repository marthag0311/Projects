# Event Analytics Power BI Dashboard Project

The goal was to analyze event registration data and build a dashboard that supports planning, coordination, and operational decision-making for the event.

The Power BI dashboard was designed to answer key operational questions, such as:
 • How many participants are expected?
 • Are operational teams adequately staffed across different functions?
 • How many children are expected to attend?
 • How many participants traveling from other regions or countries require accommodation support?
 • How are registrations trending over time, and how can communication be adjusted?

# Key Insights Delivered

The dashboard helped:
 • Support capacity planning => Registrations by event date (e.g., 401 vs. 332 vs. 357 vs. 354) helped plan venue space, seating, and catering.

 • Identify staffing gaps => Volunteer distribution (e.g., Ushering 43 vs. Medical 4) revealed imbalances and the need for additional support.

 • Prepare family-friendly facilities => 72 children registrations informed planning for childcare and safe spaces.

 • Plan accommodation and travel support => Country data (e.g., Belgium 354, France 79, Germany 30) showed international participation, while 74 support requests guided logistics planning.

 • Track and respond to registration trends => Low engagement periods (e.g., 17 registrations in Week 3 – June) helped adjust communication to boost participation.
