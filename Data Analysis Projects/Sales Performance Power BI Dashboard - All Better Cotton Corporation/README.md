# Sales Performance Power BI Dashboard Project

The project focused on building a structured, insight-driven dashboard across:
- Performance overview
- Customer insights
- Logistics & Inventory

The goal was to answer real business questions such as
- What products drive revenue vs. profitability?
- Which customers and regions matter most?
- How efficient are our logistics?

## Specifications
- Cleaned and transformed data (types, duplicates, keys, splits, date table creation)
- Designed a star schema with proper relationships
- Created DAX measures (Revenue, Profit, Margin %, YoY, AOV, Inventory)
- Built a clean, interactive multi-page dashboard with slicers

## Insights
- Average shipping time is 22 days vs a 15-day target → clear logistics delays
- Shippers handle far more shipments than orders (e.g., SafeAndFast: 4,875 shipments vs 1,647 orders) → possible inefficiencies
- High-volume products ≠ high revenue and high-revenue products ≠ most profitable. There’s a clear trade-off between volume, revenue, and margin.
